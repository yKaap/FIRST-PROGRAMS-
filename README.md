# Biglietto Personalizzato

🇮🇹
In questo repository possiamo osservare il primo codice sviluppato da me e un altro compagno di classe e questo programma consiste nel creare un sistema che crea biglietti in base a delle richieste come il nome (Persona), Evento da assistere e il posto che è stato assegnato. In questo codice (sottolineo, sviluppato per C) possiamo osservare che usiamo argc e argv oltre all'utilizzo di char e con queste due nuove funzioni che stiamo studiando in classe notiamo che abbiamo inserito argc poichè serve proprio per contare (infatti è l'abbreviazione di Argument Counter e l'abbiamo dichiarato con int che significa intero) e l'== 4 che lo succede, serve proprio per i parametri che ci chiederà durante l'esecuzione; argv l'abbiamo usato perchè fa passare i dati attraverso il terminale e argv significa Argument Vector e in sostanza noi abbiamo fatto char *argv poichè rappresenta un array di caratteri; infine notiamo anche un return 0 che serve per comunicare a noi utenti che il programma è stato eseguito e terminato senza errori.

In this repository, we can see the first code developed by me and another classmate. This program consists of creating a system that creates tickets based on requests such as the name (Person), the event to attend, and the seat assigned. In this code (I emphasize, developed for C), we can see that we use argc and argv in addition to the use of char. With these two new functions we're studying in class, we note that we've included argc because it's used for counting (in fact, it's short for Argument Counter and we declared it with int, which means integer), and the == 4 that follows it is used specifically for the parameters it will ask us for during execution. We used argv because it passes data through the terminal, and argv stands for Argument Vector, and essentially, we made char *argv because it represents an array of characters. Finally, we also note a return 0, which is used to inform us users that the program was executed and completed without errors.
